# GitHub Language Zoo 🦁

A deliberately ridiculous repository containing tiny samples of many languages GitHub Linguist recognizes, including Hack.

This is a fun language-detection experiment, not one program that is meant to compile as a whole.

## Important
GitHub Linguist knows **hundreds** of language definitions, including programming, markup, data, and prose types. This starter zoo contains a broad set of recognizable languages rather than literally every entry in Linguist's enormous `languages.yml`.

If you want the truly absurd version, generate one sample for every current Linguist language entry.

## `.gitignore` warning
If you put these source files in `.gitignore` **after they are already committed**, Git does not stop tracking them. `.gitignore` mainly prevents untracked files from being added.

Also, if your goal is to make the GitHub Languages bar show the zoo, don't ignore the files before committing them.

GitHub's Languages bar is calculated by Linguist from the default branch.
